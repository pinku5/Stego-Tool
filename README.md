# Stego-Tool

Stego Tool
A simple Python-based steganography tool for Termux that allows users to hide and extract secret messages inside images.

°°°Features

Hide secret text messages inside images
Extract hidden messages from encoded images
Password-protected message encryption
Automatic JPG/JPEG to PNG conversion
PNG image support for reliable data storage
Image information viewer
Capacity checker to estimate maximum message size
Colorful and user-friendly terminal interface
Lightweight and easy to use in Termux

°°°Requirements

Python 3
Pillow
Colorama
Installation
pip install pillow colorama

°°°Usage

Run the tool:
python stego.py
Choose an option from the menu:
Hide Message
Extract Message
Image Info
Capacity Checker
Exit
